# Debian 13 Trixie pour la physique en BTS CIEL

Documentation pour l'installation de Debian 13 pour l'enseignement de la physique en BTS CIEL.

## Sommaire

- [Système](systeme.md) : AppImage, Flatpak et Flathub, imprimantes.
- [Gnome](gnome.md) : ajustements, extensions, éditeur de menu, aperçu rapide dans Nautilus.
- [Web](web.md) : Chromium, affichage Wayland, accélération vidéo.
- [Multimédia](multimedia.md) : codecs audio et vidéo, VLC.
- [Bureautique](bureautique.md) : LibreOffice, PDF Arranger, captures d'écran avec Ksnip et Gradia.
- [Markdown](markdown.md) : éditeur MarkText.
- [LaTeX](latex.md) : installation minimale pour Pandoc.
- [VS Code](vscode.md) : installation depuis le dépôt Microsoft, accès aux ports série.
- [Python](python.md) : pip et environnements virtuels, Thonny, Spyder, Jupyter.
- [Microcontrôleurs](microcontroleurs.md) : Arduino IDE 2, ESP32, STM32.
- [Oscilloscope](oscilloscope.md) : enregistrement des fichiers Siglent sur l'ordinateur par le réseau.
- [Interfaces](interfaces.md) : ADALM2000 (M2K), Analog Discovery 3.
- [Radio logicielle (SDR)](sdr.md) : GNU Radio, Gqrx, USRP B200, ADALM-Pluto.
- [Simulation](simulation.md) : LTspice avec Wine.
- [PCB](pcb.md) : KiCad, FlatCAM.
- [Wine](wine.md) : Wine 64 et 32 bits, Winetricks, polices Microsoft.
